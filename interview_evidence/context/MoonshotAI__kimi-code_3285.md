## 5. Educational Concepts
### CLI Argument Aliasing
- **What is it:** Allowing multiple command-line flags (like -S and -r) to point to the exact same underlying option.
- **Why it matters:** Ensures that user documentation, error messages, and actual CLI parser capabilities remain perfectly in sync so users aren't given broken instructions.
- **Connection to Issue:** Fixes the discrepancy where the exit message instructs users to use `-r`, but only `-S` is recognized by the CLI.

### Command-Line Interface Help Text Generation
- **What is it:** The self-documenting usage and option descriptions generated by CLI parsing libraries such as Commander.js.
- **Why it matters:** Developers rely on help text to discover available flags and correct syntax without needing to check external documentation.
- **Connection to Issue:** Ensures that whichever option flag (-r or -S) is chosen as the canonical resumption method is clearly documented in `kimi --help`.
